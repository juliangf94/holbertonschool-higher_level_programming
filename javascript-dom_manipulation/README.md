# JavaScript - DOM Manipulation

## Description
This project focuses on manipulating the DOM (Document Object Model) using JavaScript. It covers selecting elements, handling events, modifying styles and classes, and fetching data from external APIs using the Fetch API.

## Learning Objectives
* How to select HTML elements using JavaScript.
* How to differentiate between `querySelector`, `getElementById`, and `getElementsByClassName`.
* How to handle user events like `click`.
* How to modify the style and classes of an element.
* How to create and append new HTML elements dynamically.
* How to use the Fetch API to retrieve data from a remote server.
* How to manage asynchronous code using Promises.

## Requirements
* Allowed editors: `vi`, `vim`, `emacs`, `Visual Studio Code`.
* All files are interpreted on Chrome (version 57.0 or later).
* All files should end with a new line.
* A `README.md` file, at the root of the folder of the project, is mandatory.
* Your code should be `semistandard` compliant.
* You are not allowed to use `var`.

## Tasks

| Task | File | Description |
| :--- | :--- | :--- |
| **0. Click and turn red** | `0-script.js` | Updates the text color of the `<header>` element to red (#FF0000) when the user clicks on the tag with id `red_header`. |
| **1. Click and turn red** | `1-script.js` | Same as task 0, but ensures the script works regardless of where it is imported. |
| **2. Add .red class** | `2-script.js` | Adds the class `red` to the `<header>` element when the user clicks on the tag with id `red_header`. |
| **3. Toggle classes** | `3-script.js` | Toggles the class of the `<header>` element between `red` and `green` when the user clicks on the tag with id `toggle_header`. |
| **4. List of elements** | `4-script.js` | Adds a `<li>` element to a list when the user clicks on the element with id `add_item`. |
| **5. Change the text** | `5-script.js` | Updates the text of the `<header>` element to "New Header!!!" when the user clicks on the element with id `update_header`. |
| **6. Star wars character** | `6-script.js` | Fetches and displays the character name from the Star Wars API in the HTML tag with id `character`. |
| **7. Star wars movies** | `7-script.js` | Fetches and lists the title for all Star Wars movies in the `<ul>` element with id `list_movies`. |
| **8. Say Hello!** | `8-script.js` | Fetches a translation of "hello" from an API and displays it in the element with id `hello`. Works when imported from the `<head>`. |
